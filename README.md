# Walmart Sales Analysis

## 📌 Project Overview

This project analyzes customer purchase behavior using the Walmart sales dataset.

The analysis focuses on exploratory data analysis, statistical analysis, confidence intervals, and comparison of customer purchase patterns across different demographic groups.

## 🎯 Business Questions

- Is there a significant difference in average purchase amount between male and female customers?
- Is there a difference in purchase behavior between married and unmarried customers?
- What can confidence intervals tell us about the population mean purchase amount?
- How can statistical analysis support better understanding of customer behavior?

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn
- Google Colab

## 🔍 Analysis Performed

- Data cleaning and preprocessing
- Data type and missing-value analysis
- Outlier detection
- Exploratory Data Analysis
- Sampling and distribution analysis
- Confidence Interval analysis
- Statistical comparison of customer groups

## 💡 Key Insights

- Male and female customers show differences in average purchase amounts.
- Purchase behavior was compared between married and unmarried customers.
- 99% confidence intervals were calculated to estimate population mean purchase amounts.
- Statistical analysis helps identify differences in customer purchasing behavior.
